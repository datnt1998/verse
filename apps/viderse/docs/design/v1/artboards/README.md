Bản sao mã artboard đã publish (canvas “Viderse — Thiết kế UI/UX”, phiên bản 60, ngày 01/11/2026). Mở bằng một server tĩnh, ví dụ từ gốc repo verse `npx serve apps/viderse/docs/design/v1` rồi vào `/artboards/Main.dc.html` (mở thẳng `file://` thì icon không hiện vì trình duyệt chặn `mask-image`). Cần mạng để tải font Google.

- `support.js` là runtime hiển thị artboard (`<x-dc>`, `sc-for`, `sc-if`, `{{...}}`, tweak `data-props`). Không phải code sản phẩm; đừng import vào app.
- Icon nằm ở `../icons/` (Iconsax, nét Linear), dùng qua `mask-image`. App dùng cùng tên tệp.
- Ảnh minh hoạ nằm ở `../img/` (JPG 1280×720). Đây là ảnh mẫu đóng vai ảnh Hoạ sĩ vẽ, thumbnail và clip nền; app hiển thị ảnh thật của người dùng. Quy tắc ở [components › Ảnh trong giao diện](../04-components.md#c-imagery).
- **Tweak** là các trạng thái của một màn. Trong canvas, đổi tweak ở bảng bên phải. Khi mở tệp trực tiếp, sửa `default` trong `data-props` ở cuối tệp.
- Mỗi trạng thái nói tới trong spec đều có một giá trị tweak ở bảng dưới.
